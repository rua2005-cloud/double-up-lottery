# REVOLT 95 — SUPER 85〜90% / 最大80セット版

オリジナルのブラウザ確率シミュレーターです。実際の金銭や景品を使用せず、実機・メーカーとは無関係です。

## 現行仕様

- **設計機械割97.998966%（画面表示98.00%）**
- AT全体の上限は**80セット**。通常RUSHの3セットを含むため、SUPER部分の上限は77セットです。80セット目の払い出し後は継続抽選を行わず終了します。
- 通常RUSHは従来どおり75%継続を3連続成功するとSUPER突入。通常RUSHのセット長も変更しません。
- SUPERは**85%継続開始、成功ごとに+1ポイント、最大90%固定**。SUPER専用に100G・200Gセットを搭載。
- ULTRA、94%／95%上限抽選、SUPER連続突入による特殊抽選はありません。
- 純増は全AT共通9枚/G、BETは全モード3枚/Gです。

## 遊び方・保存と分析

通常時・CZ・ボーナス・ATをボタンで進行できます。AUTO ×10／×100はCZ1回から次の通常時までを1サイクルとして自動実行します。詳細画面ではCZ・ボーナス・RUSH・SUPER継続率・セットG数・差枚を分析でき、直近最大3,000サイクルをCSV出力できます。

古いバージョンの保存データを読み込んだ際、累計差枚・ゲーム数・履歴は保持しますが、旧ルールで記録した詳細分析行は混在を防ぐため消去します。旧仕様で進行中のSUPERは、新仕様へ移行して続行します。リセットボタンで最初から新仕様として遊べます。古いプレイ結果を新仕様として再計算するわけではありません。

## 起動・更新・自動テスト

ES Modulesを利用するので、`index.html` はHTTP配信してください。

```sh
python3 -m http.server 8000
# http://localhost:8000/revolt95/
node --test revolt95/tests/game-engine.test.mjs
node revolt95/build-standalone.mjs
node revolt95/build-standalone.mjs --check
```

`standalone.html` はオフライン単体HTMLで、生成スクリプト `build-standalone.mjs` により `index.html`・`style.css`・`app.js`・`game-engine.mjs` を単一ファイルにまとめます。GitHub Pagesへのデプロイ前に、ゲームエンジンのテストと単独版の同期チェックを行います。
