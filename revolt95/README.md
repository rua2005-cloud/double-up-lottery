# REVOLT 95 — 現行仕様（97.81%）

実機・メーカーと無関係なオリジナル確率シミュレーター。仕様の正本は [game-engine.mjs](game-engine.mjs) の CONFIG と nextAction() です。

SUPERの上限は突入時に1回抽選され、選んだ上限で固定されます。天井・有利区間・ストック・引き戻しはありません。

## 遊び方

「通常時を消化する」でCZまで一括消化し、「CZに挑戦する」で突破抽選、ボーナスを消化してATを狙います。AUTO ×10／×100はCZ1回から通常時に戻るまでを1サイクルとして進行します。詳細分析は直近最大3,000サイクルを記録し、CSV出力できます。

## 起動と検証

index.html はES Modulesを使うため、HTTP配信してください。

```sh
python3 -m http.server 8000
# http://localhost:8000/revolt95/
node revolt95/build-standalone.mjs
node revolt95/build-standalone.mjs --check
node --test revolt95/tests/game-engine.test.mjs
```

standalone.html はオフラインで起動できる単独HTML版です。公開ページと同じゲームエンジン・画面・CSSから作成し、単独版だけを古い仕様にしないでください。

以前のブラウザ保存データは app.js の移行処理で保持されますが、過去に得た差枚・統計を現行仕様に合わせて再抽選するものではありません。
