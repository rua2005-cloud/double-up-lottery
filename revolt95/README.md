# REVOLT 95 — 1 TAP RUSH

独立した新作ブラウザゲーム（HTML / CSS / JavaScript）。実機やメーカーとは無関係なオリジナル確率シミュレーターです。画像・音声アセットも外部ライブラリも不要です。

## 遊び方

- 「通常時を消化する」でCZまでの5〜375Gを1タップで一括消化
- 「CZに挑戦する」で直前の通常時G数に応じた突破率（45〜84%）を抽選。全体平均60%
- 55%の革命ボーナス（平均+460枚／AT期待度52%）か、45%の決戦ボーナス（+60枚／AT期待度45%）
- 革命RUSHは75%を3回連続成功で上位に昇格
- 超革命RUSHは突入時99.43%で通常タイプ（90→95%まで段階アップ）、0.57%でULTRAタイプ（最初から99%で固定）
- どちらのATも10G:85%、20G:12.5%、50G:2.5%。純増+9枚/G。
- AUTO ×10／×100 は「CZ1回から通常時に戻るまで」を1サイクルとして一括進行します。
- 統計・履歴はブラウザ内の `localStorage` に自動保存。音は初期OFF。

## 仕様

| モード | 抽選 |
|---|---|
| 通常時BET | 3枚/G（全モード共通） |
| 次回CZまで | 5G 15% / 35G 15% / 160G 31% / 300G 29% / 375G 10%（平均180.1G・最大375G） |
| 通常払い出し | 0枚 75.2% / 1枚 18.4% / 3枚 6.4% |
| CZ | 11G、3枚BET。直前の通常時5G:45% / 35G:50% / 160G:55% / 300G:70% / 375G:84%で突破（加重平均60%）。各Gは約49.03%で3枚払出し（平均コスト約16.82枚） |
| 革命ボーナス | 51G (8/9) / 52G (1/9)、純増9枚/G（平均+460枚）、AT期待度52% |
| 決戦ボーナス | 16G、差枚+60枚、AT期待度45% |
| 革命RUSH | 75%で継続、3回成功で上位 |
| 超革命RUSH | 突入時99.43%で通常タイプ（90%開始、継続成功ごとに+1ポイント、95%で固定）、0.57%でULTRAタイプ（99%固定） |
| ATセット | 10G 85% / 20G 12.5% / 50G 2.5% |
| 理論機械割 | 約99.493%（表示99.49%、全ゲームのBETと払い出しを含む） |

※CZ突破率のみ直前の通常時G数に連動。それ以外は独立抽選モデル。有利区間・天井・ストック・引き戻しはなし。バーチャルコインがマイナスでも実験可能。

## 起動

`index.html` を直接ブラウザで開く方法だとES Modulesがブロックされる環境があるため、HTTP配信してください。

```sh
python3 -m http.server 8000
# http://localhost:8000
```

GitHub Pagesなど、静的ファイルを配信できるホスティングでそのまま動きます。外部API・ビルド作業不要。

## テスト

```sh
node --test tests/game-engine.test.mjs
```

ロジックは `game-engine.mjs`、表示は `app.js`、画面は `index.html` / `style.css` に分割しています。

## 単独HTML版

`standalone.html` は外部ファイル不要です。ダブルクリックでローカルブラウザでも直接遊べます。
